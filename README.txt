Thomas Aquinas College — homepage + campus pages
================================================

Upload EVERYTHING in this folder (keeping the folder structure) to the
web root of your host, or to any subfolder. All links are relative, so it
works at either location.

  index.html        The redesigned homepage
  home.css, home.js Homepage styles and scripts
  california/       "Come and See California" funnel page
  new-england/      "Come and See New England" funnel page
  campuses/         The campus chooser (split-screen) page
  assets/logo/      Wordmark, seal, favicon

Pages:
  /              homepage
  /california/   California campus
  /new-england/  New England campus
  /campuses/     campus chooser

Static hosts (Netlify, Vercel, GitHub Pages, Cloudflare Pages, S3) can take
the zip or folder as-is. No build step, no server code.

Note: news, events and stats are written into index.html by hand; edit
them there to update. Analytics/ad tags from the old site are not included.
